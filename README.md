## 📂 Detailed Module Breakdown

### 1. 🎮 Games & GUI Applications
- **`Dragon tiger`**: Complete Java Swing GUI card game featuring:
  - Interactive betting mechanism against computer dealers
  - Player balance tracking and statistics
  - Persistent high-score recording (`leaderboard.txt`)
  - Modular OOP architecture (`DragonTigerGUI`, `Game`, `Player`, `Leaderboard`)
- **`GUI`**: Swing/AWT desktop window applications demonstrating layout managers, custom frames (`myFrame.java`), buttons, and graphical asset handling.
- **`untitled1` (GUI Features)**: Includes `JeeResultGUI` for interactive examination score processing.

### 2. 🧠 Data Structures & Algorithms (DSA)
- **`linkedlist`**:
  - **Singly Linked List (`single/`)**: Dynamic node insertion (head/tail/position), deletion, forward traversal, searching, and length calculation.
  - **Doubly Linked List (`doubleLinkedList/`)**: Bidirectional node linkage, forward and backward traversal, and node removal.
- **`DSA assig 1`**: Fundamental algorithms, Spy number validation, BMI calculations, and mathematical proofs.
- **`dsa assin2`**:
  - Geometric modeling (`PointType`, `CircleType`) with distance calculation.
  - Domain modeling and inheritance (`Student`, `Employee`, `Manager`, `Sport`, `Bank`).

### 3. ⚡ Algorithm Analysis & Design (AAD)
- **`AAD`**, **`aad2`**, **`ad_practice`**, **`assigAD4`**, **`assig3`**:
  - Classical sorting algorithms (Selection Sort, etc.)
  - Time and space complexity benchmarking
  - Iterative vs recursive problem solving

### 4. 📚 Core Java Coursework (`Assignment 1 - 7`)
- **`Assignment1`**: Syntax fundamentals, standard I/O with `Scanner`, basic arithmetic.
- **`assignment2` & `Assignment 5`**: Conditional logic (`if-else`, `switch`), nested decision making, and loop control.
- **`Assignment3` & `Assignment4`**: Iteration (`for`, `while`, `do-while`), number reversal, series summation, prime verification.
- **`Assignment 6`**: Functional decomposition, methods, parameters, recursion.
- **`Assignment 7`**: 1D and 2D arrays, matrix arithmetic, vector processing.
- **`Classwork loop practice`**: Specialized pattern printing algorithms including Butterfly patterns, diamonds, triangles, and number pyramids.

### 5. 🎯 LeetCode & Problem Solving
- **`leet code`**: Solutions to standard algorithmic challenges optimized for time and memory constraints.
- **`untitled1`**: Fibonacci sequence generators, LCM/GCD calculators, Date utilities, and array aggregation algorithms.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Nishant20361/intelli-project.git
cd intelli-project
```

### 2. Open in IntelliJ IDEA
1. Launch **IntelliJ IDEA**.
2. Select **File > Open...** and choose the `intelli-project` root directory (or any individual subproject).
3. Ensure the project SDK is configured: **File > Project Structure > Project > SDK** (Select Java 17+ or your installed JDK).

### 3. Run via Command Line
To compile and run any individual Java file directly from the terminal:
```bash
# Example: Running Dragon Tiger GUI Game
cd "Dragon tiger/src"
javac practice/*.java
java practice.Main

# Example: Running Linked List
cd "../../linkedlist/src"
javac single/Sinle.java
java single.Sinle
```
